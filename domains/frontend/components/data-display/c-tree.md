## 是什么

可展开收起的层级列表，每级缩进，节点可选中、勾选或按需加载。

## 适合

真实的层级数据：文件目录、组织架构、分类管理、权限树。

## 不适合

只有两级且第二级很少时用分组列表；层级只是为了归类展示时用分组标题；需要逐级选出一个值时用级联选择。

## 要点

- 每级缩进 16–24px，行高 32px（紧凑 28px）；展开箭头 16px，叶子节点留出同宽占位保持对齐
- 当前选中节点浅主色底 + 主色文字，悬停浅灰底；勾选树的父节点有选中 / 未选 / 部分选中三态
- role="tree" / "treeitem" / "group"，展开节点设 aria-expanded；漫游焦点，整棵树只占一个 Tab 位
- 键盘：上下移动，右键展开或进入子级，左键收起或回到父级，Enter 选中，Home / End 到首尾
- 按需加载子级时箭头位置显示 16px 转圈，失败在该节点下显示“加载失败，重试”
- 名称过长单行省略并悬停显示全文；节点很多时顶部提供搜索并自动展开命中路径

## 提示词

把{文档空间的目录}做成树：每级缩进 20px，行高 32px，展开箭头 16px，叶子节点留同宽占位；当前节点浅主色底加主色文字，悬停浅灰底；用 role="tree" / "treeitem" / "group" 和 aria-expanded，漫游焦点只占一个 Tab 位；方向键上下移动、右键展开或进入子级、左键收起或回父级、Enter 打开、Home / End 到首尾；子级按需加载时箭头处显示转圈，失败显示“重试”；名称过长省略；顶部搜索自动展开命中路径；窄屏收进抽屉。
