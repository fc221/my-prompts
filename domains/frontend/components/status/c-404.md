## 是什么

页面不存在或服务出错时的整页说明，带“返回首页”“重试”等出路。

## 适合

链接失效、地址输错（404）、服务器异常（500）、系统维护（503）。

## 不适合

区块级的失败在区块内处理；不放与产品无关的搞笑插画；不做自动倒计时跳转。

## 要点

- 用组件库的结果页：Element Plus el-result（title、sub-title、icon，按钮放 extra 插槽；没有 404 / 500 预设，状态码或插图放 icon 插槽）、Naive UI n-result（status="404" / "500"、title、description，按钮放 footer 插槽）、Ant Design Vue a-result（status="404" / "500"、title、subTitle，按钮放 extra 插槽）
- 标题写人话（“页面不存在”“服务暂时出了点问题”“系统维护中”），副标题写一句可能的原因；状态码留给组件的插图或副标题，不当主标题
- 出路最多 2 个：返回首页 + 上一页或搜索；500 类换成“重试”并附请求编号；维护页写预计恢复时间，不做自动倒计时跳转
- 结果页放在布局的内容区里，顶栏和全局导航照常渲染，用户能去别处；只影响一个区块的失败用「错误状态与重试」
- 服务端真实返回 404 / 500 状态码，不用 200 返回错误页；document.title 同步写成“页面不存在 - 产品名”
- 窄屏按钮占满宽度、上下堆叠

## 提示词

为{产品}做 404 与异常页：用项目组件库自带的结果页（Element Plus el-result title + sub-title，icon 插槽放状态码或插图，按钮放 extra 插槽；Naive UI n-result status="404" / "500" + title + description，按钮放 footer 插槽；Ant Design Vue a-result status="404" / "500" + title + subTitle，按钮放 extra 插槽），不手写，放在布局内容区里，顶栏和全局导航照常显示。标题用“页面不存在” / “服务暂时出了点问题” / “系统维护中”，副标题写一句原因；出路 2 个：返回首页、上一页或搜索；500 类给“重试”和请求编号；维护页写预计恢复时间；不自动倒计时跳转，不放无关的搞笑插画；服务端真实返回 404 / 500 状态码；document.title 同步为“页面不存在 - {产品}”；窄屏按钮占满宽度。

export default function demo(root) {
  const V = [
    ['404', '页面不存在', '链接可能已失效，或地址输入有误。', '返回首页', '上一页'],
    ['500', '服务暂时出了点问题', '我们已记录这个错误（编号 a81c02），请稍后重试。', '重试', '返回首页'],
  ];
  const ct = root.querySelector('.ct'), seg = [...root.querySelectorAll('.seg button')];
  const show = (k) => { seg.forEach((b, j) => b.setAttribute('aria-pressed', String(j === k))); const v = V[k]; ct.innerHTML = `<p class="code">${v[0]}</p><h4>${v[1]}</h4><p class="muted">${v[2]}</p><div class="ac"><button class="b p">${v[3]}</button><button class="b">${v[4]}</button></div>`; };
  seg.forEach((b, k) => b.addEventListener('click', () => show(k)));
  show(0);
}
</script>
