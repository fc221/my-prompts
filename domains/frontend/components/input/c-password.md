## 是什么

输入显示为圆点，右侧按钮切换明文，下方逐条显示规则是否满足。

## 适合

登录、注册、修改密码、填写需要保密的令牌。

## 不适合

不要用“再输入一次密码”代替显示切换；验证码不用密码框；不要禁止粘贴，会妨碍密码管理器。

## 要点

- 右侧显示 / 隐藏按钮是 button，aria-label 随状态在“显示密码 / 隐藏密码”间切换，并设 aria-pressed
- 图标 16px 离右边框 12px，文字右内边距 40px；切换后焦点不跳走
- autocomplete 区分：登录用 current-password，注册和改密用 new-password；关闭拼写检查和自动大写
- 注册时规则写在框下方（至少 8 位、包含字母和数字），满足一条勾一条，不要等提交后才报错
- 检测到大写锁定时在框下提示“大写锁定已打开”
- 强度提示只做辅助，用“弱 / 中 / 强”文字，不只靠颜色

## 提示词

把{注册页的“设置密码”}做成密码框：高 40px（触屏 44px），右侧眼睛按钮离边框 12px，切换明文时 aria-label 在“显示密码 / 隐藏密码”间变化并设 aria-pressed，焦点不跳走；autocomplete="new-password"，关闭拼写检查和自动大写；框下逐条列出规则（至少 8 位、包含字母和数字），满足一条勾一条；检测到大写锁定时提示；允许粘贴；错误时边框变红并用 aria-describedby 关联说明；窄屏撑满。
