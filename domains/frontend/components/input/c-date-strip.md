## 是什么

手机页面上方一条横向滑动的日期，下面是当天内容，日期和内容同屏；点日期或左右滑内容都能换天，选中态跟着走，今天有标记。

## 适合

课表、排班、赛程、影院场次、预约时段：按天看内容，大多数时候看今天前后几天。

## 不适合

跨月挑任意日期用「日期与时间选择」；按时段看报表用「时间范围快捷按钮」；要看一整月的分布用「日历视图」。

## 注意

滑日期带只是翻看，点了才换内容；左右滑内容会换天，选中项自动滚到日期带中间。两个滚动区要等停下来再同步，程序滚动途中读到的位置不算数。

## 要点

- 格子约 44×50px，一屏 6–7 个，右边露出半个提示还能滑
- 两行：上面周几，下面日期；今天把“周几”换成“今天”并加小圆点
- 选中态是一块实心底，在格子之间滑动约 220ms；选中项滚到日期带中间，只滚动日期带自己
- 内容区用 scroll-snap 一天一页，约 120ms 没有滚动再更新选中；点日期时内容平滑滚到那天
- 顶部月份跟着选中项变，跨月时读得出现在是哪个月
- 离开今天后出现“回今天”，回到今天时收起
- 没有内容的日子数字变灰但可以点，点开说明原因（“周一休馆”）
- role="tablist" / "tab" / "tabpanel"，左右方向键换天，Home / End 到首尾，只占一个 Tab 位
- 减少动态效果时选中态和内容直接切换

## 提示词

给{课程预约页}顶部加横滑日期带：格子 44×50px，上面周几、下面日期，今天写“今天”并加小圆点，从今天前 {天数} 天排到后 {天数} 天；下面是当天{课程列表}，内容区用 scroll-snap 一天一页；点日期时内容滚到那天，左右滑内容时等滚动停下约 120ms 再更新选中；实心选中底在格子间滑动约 220ms，选中项滚到日期带中间，只滚动日期带自己；滑日期带本身不改变选中；顶部月份随选中项变化；离开今天时显示“回今天”；没有内容的日子数字变灰，点开说明原因；用 tablist / tab / tabpanel，左右方向键换天；减少动态效果时直接切换。
