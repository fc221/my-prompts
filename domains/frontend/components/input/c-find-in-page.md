## 是什么

长文或协议顶部的查找条：高亮全部匹配，当前这处颜色更深，写着“第 3 / 12 处”，上下跳转，Esc 关闭。

## 适合

合同、协议、文档阅读器、日志和代码查看器，尤其是内容在内部滚动、虚拟滚动或折叠区里，浏览器自带查找找不全的时候。

## 不适合

普通网页用浏览器自带查找就够；在一堆记录里按关键词过滤用「搜索框」；跨页面找东西用「命令面板」。

## 注意

跳转时算好偏移量，只滚动内容容器，当前这处停在可视区上方三分之一，上下文都看得见。

## 要点

- 查找条固定在内容区顶部，打开时内容不跳动；排列是 输入框、计数、上一处、下一处、关闭
- 其他匹配浅黄底，当前这处深橙底，两者差别一眼可见，文字对比度保持 ≥ 4.5:1
- 输入后约 120ms 再查；输入法组字时不查，确认后再查
- Enter 下一处，Shift + Enter 上一处，到末尾回到第一处
- 按 Esc 或关闭后清掉高亮，焦点回到“查找”按钮，滚动位置留在当前这处
- 焦点在阅读区内时接管 ⌘F / Ctrl+F；打开时若有选中文字，自动填进输入框
- 没有匹配时计数写“没有找到”，输入框浅红底，上下按钮禁用
- 匹配落在折叠段落里时自动展开；虚拟滚动的内容要在数据上查，跳转时再渲染那一段
- 高亮优先用 CSS Custom Highlight API，不改 DOM；环境不支持时退回包 mark 标签
- 计数用 role="status" 播报；减少动态效果时直接跳转，不平滑滚动

## 提示词

给{协议阅读页}加页内查找：内容区顶部的“查找”按钮打开查找条，排列是 输入框、“第 N / M 处”、上一处、下一处、关闭；输入后约 120ms 高亮全部匹配，输入法组字时不查；其他匹配浅黄底，当前这处深橙底；Enter 下一处，Shift + Enter 上一处，到末尾回到第一处；跳转时只滚动内容容器，当前这处停在可视区上方三分之一，减少动态效果时直接跳；无匹配时写“没有找到”、输入框浅红底、上下按钮禁用；Esc 关闭并清高亮，焦点回到“查找”按钮，滚动位置保留；焦点在阅读区内时接管 ⌘F / Ctrl+F，有选中文字时自动填入；默认不区分大小写；匹配在折叠段落里时自动展开；计数用 role="status" 播报。
