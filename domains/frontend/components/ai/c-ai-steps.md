## 是什么

回答上方一行可展开的摘要，展开后逐条列出每一步、调用了什么工具、参数和结果。

## 适合

Agent 执行多步任务、调用搜索 / 代码 / 文件工具、需要让用户追溯过程的场景。

## 不适合

不要把每个事件打成一行系统文本；简单的一问一答不显示过程；不用计时器假装进度。

## 要点

- 运行中显示“正在{步骤} · 第 2 / 3 步”并默认展开；完成后自动收起成“已完成 3 步 · 用时 12 秒”
- 同一个工具调用合并成一项：状态图标 + 工具名 + 参数 + 结果摘要或错误
- 状态以后端事件为准，至少区分排队、运行中、完成、出错、已取消；“正在停止”和“已停止”分开显示
- 写入、删除、外发类操作先出授权卡：要执行什么、影响哪些对象，用户确认后才执行
- 展开收起不改变上方内容的位置；计时和计数用等宽数字，不横跳
- 折叠用 button + aria-expanded，收起后内容不可聚焦

## 提示词

为{Agent 执行过程}做「思考过程与工具调用」展示：回答上方一行可折叠的摘要，运行中写“正在{步骤} · 第 2 / 3 步”并默认展开，完成后自动收起为“已完成 3 步 · 用时 12 秒”；展开后每步一行：状态图标（排队 / 运行中 / 完成 / 出错 / 已取消）+ 工具名 + 参数 + 结果摘要，同一调用合并成一项；状态以后端事件为准；写入、删除、外发类操作先出授权卡；折叠用 button + aria-expanded，计时用等宽数字。
