## 是什么

检查首屏速度、交互响应和布局稳定，用真实设备和弱网实测，不凭一次跑分下结论。

## 要点

- LCP ≤ 2.5s，INP ≤ 200ms，CLS ≤ 0.1（真实用户第 75 百分位，手机桌面分开看）。
- 首屏主图设 fetchpriority="high"，非首屏图片设 loading="lazy"。
- 图片写明宽高或 aspect-ratio，用 srcset 按屏宽供图，优先 WebP / AVIF。
- 字体做子集、font-display: swap，最多两种字体家族。
- 首屏 JS 和 CSS 尽量小，非首屏模块按需加载，第三方脚本延后加载。
- 超过约 200 条的列表用分页或虚拟列表。
- 搜索输入防抖 250–300ms；切换筛选时取消或忽略过期请求。
- 滚动、拖动、输入的处理函数里不做重计算，不在循环里交替读写布局。
- 动画只动 transform 和 opacity；大面积元素不持续使用 blur 和 backdrop-filter。
- 循环动画和轮播在离开视口或页面隐藏时暂停。
- 不用大背景视频、大图或长动画掩盖交互迟缓。
- 在弱网（如 4G 限速）和中低端手机上实测首屏与交互，记录真实数据。

## 提示词

请按以下清单逐项检查我的页面，列出不符合的项并修复：
{{要点}}

检查方式：在 1440 和 390 宽各看一遍，逐项标“通过 / 不通过 / 未验证”；不通过的直接修复并说明改了什么；无法验证的写明原因，不要默认通过。
