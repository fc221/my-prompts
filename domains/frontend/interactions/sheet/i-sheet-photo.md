## 是什么

点列表里的照片卡片，照片从卡片位置放大铺满上半屏，接着抽屉从底部滑上来，顶边正好压住照片下沿一个圆角的高度，标题叠在照片上；关闭时倒序收回。

## 适合

地点、民宿、菜品、作品、商品这类“图是主角、下面接摘要和操作”的卡片列表进详情。

## 不适合

没有图或图不重要时用普通底部面板或直接进详情页；详情很长（评论、规格表）时进完整详情页，抽屉里只放摘要和一两个操作；桌面宽屏改用侧边详情面板。

## 注意

关闭严格倒序：先收抽屉，再把照片缩回原卡片，最后把焦点还给那张卡片；照片的位移和缩放只用 transform（FLIP），不要动 width / height / top。

## 要点

- FLIP：先量卡片缩略图和终点的位置尺寸，照片用 transform 从卡片位置放大到上半屏（约 56% 高），380ms、cubic-bezier(.2,.8,.2,1)，圆角 10px → 0。
- 飞行期间隐藏原卡片的缩略图，看起来就是同一张图在移动。
- 照片快落定时（约 340ms）抽屉从底部 translateY(100%) 滑上，320ms 缓出；顶边停在照片下沿往上 16px，正好等于抽屉顶部圆角。
- 标题和副标题叠在照片底部、抽屉上方，照片底部加 0 → 55% 左右的黑色渐变保证白字对比度。
- 关闭：抽屉 240ms 收下 → 照片 320ms 缩回原卡片 → 焦点回到原卡片；关闭按钮和 Esc 都能关。
- 详情层用 role="dialog" 并以标题命名，打开后焦点移到关闭按钮，背景列表设 inert。
- 减少动态效果时不做飞行和滑动，照片与抽屉直接出现、直接消失。

## 提示词

给{产品}的{照片卡片列表}做「大图 + 贴边抽屉」：点一张卡片，照片用 FLIP（只用 transform）从卡片位置放大铺满上半屏（约 56% 高，380ms 缓出，圆角 10px→0），飞行时隐藏原缩略图；照片快落定时抽屉从底部滑上（320ms 缓出），顶边正好停在照片下沿往上 16px，压住照片一个圆角的高度；{标题}叠在照片底部的暗色渐变上；抽屉里放{详情摘要}和{操作按钮}；关闭严格倒序：先收抽屉，再把照片缩回原卡片，焦点回到原卡片；Esc 可关，详情层 role="dialog"、背景设 inert；减少动态效果时直接显示和隐藏。
