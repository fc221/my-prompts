## 是什么

左边两栏：最左一列窄栏只放一级模块的图标和短名，旁边一列列出当前模块的页面，右侧是内容区。模块多、每个模块下页面也多时，比把整棵菜单树塞进一根侧栏清楚。

## 适合

模块 6 个以上、每个模块 5 页以上的大后台；用户大部分时间待在一个模块里。

## 不适合

模块 3 个以内直接用「侧栏 + 顶栏」；二级页面只有一两个的模块第二栏空荡，这类模块点图标直接进页面。

## 要点

- 第一栏 64–80px：图标在上、短名在下，当前模块实心强调底；第二栏 200–220px 列当前模块的页面，当前页高亮
- 切换模块时第二栏换内容并进该模块的第一个页面，或记住上次打开的页面
- 模块只有一个页面时不展开第二栏，点图标直接进页面
- 第二栏可收起，收起后悬停第一栏图标弹出该模块的页面列表，做法同「图标窄栏导航」
- 第一栏的样子有图标竖排、图标加文字、卡片、箭头几种，全站只选一种
- 窄于 1024px 两栏合成一棵导航树收进左侧抽屉

## 提示词

给{产品}的后台做分栏导航：最左 72px 一栏放 {模块清单} 的图标和短名，当前模块实心强调底；旁边 208px 一栏列当前模块的页面，当前页高亮；切模块时第二栏换成该模块的页面并进第一个页面（记住上次打开的也可）；模块只有一个页面时不展开第二栏，点图标直接进页面；第二栏可收起，收起后悬停图标弹出页面列表；顶栏放搜索、通知、账号；1024px 以下两栏合成导航树收进左侧抽屉。

## 示意图

```js
export const wire = {
  cols: '72px 208px 1fr',
  rows: '14% 1fr',
  areas: ['rail sub top', 'rail sub main'],
  boxes: {
    rail: { label: '模块栏', dark: true, acc: true },
    sub: { label: '当前模块的页面列表', kind: 'nav', acc: true },
    top: '顶栏',
    main: '订单表格',
  },
};
export const wireMobile = {
  cols: '1fr',
  rows: 'auto 1fr',
  areas: ['top', 'main'],
  boxes: { top: { label: '顶栏 ☰', acc: true }, main: '订单表格' },
  drawer: { size: '70%', box: { label: '导航树（左侧抽屉）', dark: true, kind: 'nav', acc: true } },
};
```
