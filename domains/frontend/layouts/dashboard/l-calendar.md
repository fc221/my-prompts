## 是什么

左侧“新建日程”和日历分类，右侧月视图网格，每天的格子里放彩色日程条；顶部切换月 / 周 / 日。

## 适合

排期、预约、活动、值班、内容发布计划等按日期安排的事。

## 不适合

事项没有固定日期、只关心先后顺序时用看板或列表；按人看占用时用时间轴泳道。

## 要点

- 顶部：当前月份、上一月 / 下一月、“今天”按钮和“月 / 周 / 日”切换；今天的日期用主色圆点标出
- 日程条按日历分类着色，同一天放不下时显示“+N 项”，点开浮层列出全部
- 点空白格子直接打开快速新建，日期已经按这一格填好；拖动日程条改日期；跨天日程画成连续的长条
- 翻到别的月份后，“今天”按钮一步跳回今天所在的月份并选中今天
- 左侧日历分类可勾选显示 / 隐藏，颜色和日程条一致；不只靠颜色区分，条上写名称
- 周视图和日视图按小时排，当前时间画一条横线
- 手机上默认显示日程列表（按天分组）加顶部一周日期条，点日期跳到当天

## 提示词

{产品}的{日程页}用「日历视图」：左侧 240px 放“新建日程”按钮和可勾选的日历分类（{分类}，各有颜色）；右侧顶部当前月份、上 / 下月、“今天”按钮和“月 / 周 / 日”切换；月视图 7 × 5 网格，今天用主色圆点标出，每格放按分类着色并写名称的日程条，放不下显示“+N 项”点开浮层；点空白格打开快速新建（日期按这一格填好）、拖动改日期，“今天”一步跳回并选中今天，跨天日程画连续长条；周 / 日视图按小时排并画当前时间线；手机上改成顶部一周日期条 + 按天分组的日程列表。
