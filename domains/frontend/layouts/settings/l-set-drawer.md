## 是什么

顶栏右上角的设置按钮打开右侧抽屉，里面是主题色、明暗模式、布局方式等界面偏好，改了页面马上变，背后的页面能直接看到效果。

## 适合

后台的外观和布局偏好：主题、布局方式（侧边栏 / 顶部导航 / 综合）、侧栏样式、菜单折叠、页面动画。

## 不适合

业务配置不要放进抽屉，用设置页；选项超过一屏时也改用设置页。

## 要点

- 抽屉宽 320–360px，从右侧滑入，标题“界面设置”和关闭按钮；遮罩淡一些，让背后的页面看得到
- 每项改了立刻生效，背后页面同步变化，不需要“保存”；偏好存在本地或账号里
- 主题色用色块，明暗用分段按钮，布局方式用小缩略图，开关项一行一个
- 底部“恢复默认”；给开发者用的可以加“复制当前配置”
- Esc 和点遮罩关闭，焦点回到设置按钮
- 手机上改成底部面板，内容不变

## 提示词

{后台}加一个「界面设置抽屉」：顶栏右上角设置按钮打开右侧 340px 抽屉（标题“界面设置”+ 关闭），遮罩用浅色让背后页面可见；内容依次是：明暗模式分段按钮（浅色 / 深色 / 跟随系统）、主题色色块（{颜色}）、布局方式缩略图（侧边栏 / 顶部导航 / 综合）、开关项（折叠侧栏、顶部菜单居中、页面切换动画）；每项改了立即生效并记住，不需要保存；底部“恢复默认”；Esc 和点遮罩关闭，焦点回到设置按钮；手机上改成底部面板。
