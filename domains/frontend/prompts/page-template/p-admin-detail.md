## 是什么

查看和处理单个对象的详情页：头部状态与主操作、关键信息、描述列表、关联记录。

## 要点

- 填对象名、有哪几种状态、主操作是什么。
- 主操作只留 1 个，其余写进“更多”。
- 说明编辑方式：按组编辑，还是跳编辑页。
- 列出要展示的关联记录（订单、附件、操作记录等）。

## 提示词

{对象}详情页，给{角色}查看和处理单个{对象}。

结构：
1. 顶部：面包屑或返回按钮 → 对象名 + 状态标签（{状态列表}，每种用固定颜色加文字）→ 右侧操作：主按钮“{主操作}”1 个，其余（{次要操作}）收进“更多”，危险操作放在“更多”最后并与其他项隔开。
2. 关键信息条：{3–4 个最重要的字段，如 金额、负责人、创建时间}，横排，数值 20px。
3. 基本信息：描述列表，标签用次要色、值用主文字色；宽屏 3 列、中屏 2 列、窄屏 1 列；空值显示“—”；长文本（备注、地址）独占一行；编号旁放复制按钮并有“已复制”反馈。
4. 关联记录：用 Tabs 分区（{关联内容，如 关联订单、附件、操作记录}），每个 Tab 显示数量；记录多时用表格并分页。
5. 操作记录：时间倒序的时间线，写清谁在什么时间做了什么。

编辑：{按组编辑：点某组的“编辑”只把这一组切成输入框，保存或取消后回到只读 / 跳转到编辑页}；有未保存修改时离开要提示。
状态：骨架屏预留标题、信息条和描述列表的尺寸；对象不存在时显示“找不到这条{对象}”和返回列表；无权限时显示申请入口；操作成功后原位更新状态标签并给轻提示。
当前对象 ID 写进 URL，刷新后仍能打开。数据为前端示例。
