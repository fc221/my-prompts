## 是什么

App / 小程序首页：先选一种整屏构图，再定一个记忆点和唯一的主操作，避免“搜索框 + 金刚区 + 轮播 + 列表”的模板脸。

## 要点

- 先在布局板块「App 首页」里挑一种构图，写进第 1 行。
- 记忆点只要一个：超大标题、一块主色、一张满版图或一个转盘。
- 写清这一屏最想让用户做的一件事。

## 提示词

{产品}的 App / 小程序首页，用户打开最想做的一件事是：{主任务}。
1. 构图用「{构图：粗标题 + 满宽图卡流 / 满版头图 + 浮起信息卡 / 黑白单主角 / 色块打卡墙 / 海报标题 + 半圆选择盘 / 竖卡叠放翻看}」，整屏只有这一种主结构，不再叠加轮播、金刚区和第二种卡片样式。
2. 记忆点只有一个：{超大标题 / 一块饱和主色 / 一张满版图 / 一个转盘}；其余部分克制，用白卡或浅底承托。
3. 主操作只有一个：{主行动}，做成整屏最显眼的实心按钮或主卡，其它入口降为次要样式。
4. 页边距 20px，标题和卡片左边线对齐；标题最多两行；首屏露出下一块内容的顶边，提示可以滚动。
5. 颜色：{主色}只用在记忆点和主操作上；其余用黑、白、灰；图片统一比例和圆角。
6. 底部标签栏 3–5 项（{标签列表}），56px 加安全区；当前项图标和文字同时变化。
7. 有手势的地方（翻卡、转盘、横滑）都配按钮或键盘替代；减少动态效果时直接切换。
首屏要放的内容：{内容清单}。
