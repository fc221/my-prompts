## 是什么

只放必要字段的登录与注册：验证码或密码、清楚的错误提示、找得到的忘记密码。

## 要点

- 填登录方式：验证码 / 密码 / 第三方。
- 说明是否需要协议勾选。
- 写清登录成功后去哪。

## 提示词

{产品}登录 / 注册页。登录方式：{手机号 + 验证码 / 邮箱 + 密码 / 第三方登录}。

布局：桌面端左右分栏，左侧品牌区（一句话说明产品 + 一张真实产品画面），右侧表单卡片宽 400px、垂直居中；窄屏只保留表单，品牌区缩成顶部 Logo。
表单：
- 只放必要字段；标签常驻，不用 placeholder 代替；输入框高 44px、字号 16px。
- 手机号 type="tel" autocomplete="tel"；验证码 inputmode="numeric" autocomplete="one-time-code"；密码框有“显示 / 隐藏”按钮，autocomplete 区分 current-password 和 new-password。
- 获取验证码后按钮显示 60 秒倒计时，期间禁用并写“58 秒后重发”。
- 协议勾选默认不选中，协议可点开查看；未勾选就点登录时，在勾选框旁提示，不弹窗。
- 主按钮“登录”通栏，提交中显示“登录中…”并防重复；回车可提交，输入法选字时的回车不提交。
错误：账号或密码错误写在表单顶部，不清空已填账号；验证码错误写在验证码下方；多次失败后要求图形验证或稍后再试，并写清等多久；网络问题单独提示。
其他：“忘记密码”放在密码框右上方；登录和注册一键切换并保留已填手机号；第三方登录按钮统一样式放在分割线下方，在不支持的内嵌浏览器里给替代路径；登录成功后回到{来源页 / 首页}；桌面端自动聚焦第一个输入框，手机端不自动聚焦。
