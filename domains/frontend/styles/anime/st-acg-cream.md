## 是什么

奶油白底配暖深灰字，粉、薄荷、柠檬色贴纸微微倾斜，软萌可爱。

## 适合

萌系游戏、潮玩与周边商城、宠物与生活社区、轻松向的活动页。

## 不适合

不要把马卡龙色用在正文文字上（对比度不够）；不要贴纸满屏，正文区保持整洁。

## 要点

- 配色：奶油白底 #fff7e8，暖深灰 #3d3029 做文字、描边与投影；草莓粉 #ff8fab、薄荷 #8fe3c8、柠檬 #ffe27a、薰衣草 #c7b5ff 选 2–3 个做贴纸和色块
- 浅色色块上一律用暖深灰文字；主按钮选一个色并核对对比度 ≥ 4.5:1
- 形状：圆角 16–24px，2px 描边，硬投影 3px 3px 0 #3d3029（比冷白版更轻）；贴纸倾斜 ±3–6°
- 字体：标题粗圆体或系统粗体；正文系统字体 16px / 行高 1.7
- 装饰：小爱心、星星、波浪边、手写感标注，aria-hidden，不压正文
- 配图：原创萌系吉祥物或几何化角色，圆润无尖角
- 动效：轻弹、摇摆 ±3°、待机浮动；同屏循环 ≤ 3 处，减少动态效果时停止

## 提示词

把{产品}的{页面}做成二次元奶油风：奶油白底 #fff7e8，暖深灰 #3d3029 做文字、2px 描边和 3px 3px 0 硬投影；{品牌色}做主按钮，草莓粉、薄荷、柠檬中选 1–2 个只作贴纸与色块，浅色块上用深灰字；圆角 20px，贴纸倾斜 ±3–6°；标题粗圆体，正文 16px / 1.7；配原创圆润吉祥物和小爱心、星星装饰（aria-hidden）；悬停轻摇 ±3°、吉祥物待机浮动，同屏循环 ≤ 3 处，减少动态效果时停止；窄屏减少贴纸、取消倾斜。
