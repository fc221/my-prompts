## 是什么

深海蓝底上一层青色细线：面板只画四个角的折角框，配雷达扫描环、刻度尺、等宽大数字和小号大写标签，像飞船驾驶舱或城市指挥中心的抬头显示。

## 适合

城市运行和园区监控大屏、发布会与展厅的数据墙、物流调度、能源与生产看板，以及游戏或科幻作品里的仪表界面。

## 不适合

要坐下来长时间操作、录入和筛选的后台，改用「科技深色」的看板做法；只有文字和命令的工具页，用「终端命令行」；要霓虹、故障和夜城氛围的活动页，用「赛博霓虹」。

## 注意

大屏是远看的：先定 3–5 个核心读数放最大，其余缩成小号辅助，别让每个面板一样大、一样亮。折角框、刻度和扫描环都是装饰，同屏动的东西不超过 3 处，数字本身要静止可读。

## 要点

- 配色：深海蓝底 #06121f（往 #0a2236 做径向渐亮），正文 #d9f4ff（16.5:1），标签 #8fb3c9（8.5:1），线 #1d4b63；主色青 #3ee6ff 给读数和高亮，状态色只加正常绿 #5ee0a0、预警琥珀 #ffb020、告警红 #ff5d6c
- 字体：读数用等宽或窄体数字，推荐 Rajdhani 或 JetBrains Mono，后备 "DIN Alternate"、ui-monospace、Menlo、monospace，font-variant-numeric: tabular-nums，核心读数 48–96px；标签 11–12px、大写英文字距 0.12em；中文用系统无衬线 14px
- 面板：底色 rgba(62,230,255,.04)，只画四角折角（每角 10–14px、1.5px 青线，用四层 linear-gradient 背景画），标题栏左侧编号 01、02，右侧小号状态；圆角 0
- 图形：雷达环 2–3 圈 1px 线加 conic-gradient 扇形扫描，刻度尺每 10 格一长刻度，柱条用 2px 间隔的分段柱；发光只给核心读数 text-shadow 0 0 12px 青色 40%
- 版式：按 16:9 设计，三栏 1 : 2 : 1，中间放地图或雷达等主视觉，两侧上下堆面板；顶栏放标题、实时时钟和在线状态
- 动效：扫描环一圈 4s linear 循环，数字变化用 600ms 滚动计数，告警行琥珀闪烁 1s 两次后常亮；减少动态效果时扫描环静止、数字直接替换
- 适配：大屏用 transform: scale 整体等比缩放到视口，不做流式重排；手机和平板上改为单列面板列表，主视觉缩小放顶部

## 提示词

把{产品}的{监控大屏}做成科幻大屏风：深海蓝底 #06121f 向中心渐亮到 #0a2236，正文 #d9f4ff、标签 #8fb3c9、线 #1d4b63，主色青 #3ee6ff 只给读数和高亮，状态色正常 #5ee0a0、预警 #ffb020、告警 #ff5d6c；按 16:9 做三栏 1 : 2 : 1，中间放{地图 / 雷达}主视觉；面板底 rgba(62,230,255,.04)，只画四角 12px 折角框，标题栏带 01、02 编号和小号大写英文标签；核心读数 {读数名} 用 Rajdhani 或等宽字、tabular-nums、64px 以上，加一层 12px 青色发光，其余读数缩小；雷达环 conic-gradient 扫描一圈 4s，数字变化 600ms 滚动计数，告警行闪两次后常亮，同屏动画不超过 3 处，减少动态效果时扫描静止、数字直接替换；整屏用 transform: scale 等比缩放，手机上改成单列面板列表。
