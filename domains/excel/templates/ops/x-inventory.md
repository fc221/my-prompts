## 是什么

商品表管基础资料，入库表记进货、出库表记销售和领用，库存表按商品编码用 SUMIFS 汇总两张明细，算出 期初 + 入库 − 出库 = 当前库存；低于安全库存的自动标红、进预警清单并给出建议采购量，月底盘点核对账实。

## 适合

门店、小仓库、电商小卖家、食堂原材料；几百到几千个商品；想随时知道还剩多少、该补什么。

## 不适合

多仓库调拨、批次效期、扫码出入库量大的，用进销存或仓储系统，Excel 做分析；采购询价和比价用「采购清单与比价」。

## 注意

库存表全部是公式，数字一律不手改：录错了在原明细行改正并在备注写原因，或者补一笔反向的出入库。商品编码是三张表的关联键，入库、出库都只能从下拉里选编码，名称和单位用公式带出。

## 要点

- 表的关系：商品表（编码、名称、规格、单位、类别、期初数量、期初单价、安全库存、最高库存、到货天数、默认供应商）→ 入库表、出库表（按编码引用商品表）→ 库存表（一个商品一行，SUMIFS 汇总两张明细）→ 预警清单、盘点表。期初是建账日的数量，明细从建账日起记。
- 入库表列：日期、入库单号（RK-2610-0012）、编码 ▾、数量、单价、类型 ▾ 采购、退货入库、盘盈，供应商 ▾、经手人手填；名称 =XLOOKUP([@编码],商品表[编码],商品表[名称],"编码不存在")、单位同理、金额 =[@数量]*[@单价] 是公式。
- 出库表列：日期、出库单号、编码 ▾、数量、单价、类型 ▾ 销售、领用、报损、盘亏，客户或部门手填；名称、单位、金额是公式；再加一列 出库后余量 =XLOOKUP([@编码],库存[编码],库存[当前库存])，小于 0 标红，说明多出了或漏记了入库。
- 库存表列：编码、名称、期初（引用商品表）、入库合计 =SUMIFS(入库[数量],入库[编码],[@编码])、出库合计 =SUMIFS(出库[数量],出库[编码],[@编码])、当前库存 =[@期初]+[@入库合计]-[@出库合计]、安全库存、最高库存；按月看时 SUMIFS 再加日期在月初到月末的条件，得到本月入库、本月出库。
- 预警：状态 =IF([@当前库存]<0,"负库存",IF([@当前库存]<=[@安全库存],"需补货",IF([@当前库存]>[@最高库存],"积压","正常")))；建议采购量 =IF([@状态]="需补货",[@最高库存]-[@当前库存],0)；条件格式需补货整行浅红、负库存深红、积压浅黄。
- 预警清单 =FILTER(库存[[编码]:[建议采购量]],库存[状态]="需补货","没有需要补货的商品")，再用 SORTBY 按缺口从大到小排；首页或表头显示 =COUNTIF(库存[状态],"需补货")&" 个商品需补货"。
- 安全库存怎么定：日均出库 =SUMIFS(出库[数量],出库[编码],[@编码],出库[日期],">="&TODAY()-30)/30，安全库存 ≈ 日均出库 × 到货天数 × 1.2，系数按缺货代价调整，每季度复核一次。
- 金额与月底盘点：库存金额按月末一次加权平均，加权单价 =(期初金额+入库金额合计)/(期初数量+入库合计)，出库成本 = 出库数量 × 加权单价。盘点表从库存表带出编码、名称、账面数，手填实盘数，差异 = 实盘 − 账面，不为 0 标黄并写原因；审批后差异记成盘盈入库或盘亏出库，库存金额合计和总账库存商品余额核对。

## 提示词

帮我做一份{业务类型，如 咖啡店原料 / 文具店}的进销存 Excel：
1. 商品表：编码、名称、规格、单位、类别、期初数量、期初单价、安全库存、最高库存、到货天数；先录这些商品：{商品列表}。
2. 入库表、出库表：日期、单号、编码（下拉）、数量、单价、类型、供应商或客户手填；名称、单位、金额用公式；出库表加“出库后余量”列，小于 0 标红。
3. 库存表每个商品一行：期初、入库合计、出库合计（SUMIFS）、当前库存、安全库存、状态（负库存、需补货、积压、正常）、建议采购量；需补货整行浅红。
4. 预警清单用 FILTER 列出需补货的商品，按缺口排序，表头显示需补货数量。
5. 盘点表：账面数、实盘数、差异、原因。
交付时说明三张表怎么关联、哪些列手填、哪些是公式，并用 5 个商品、10 笔出入库演示预警和盘点。
