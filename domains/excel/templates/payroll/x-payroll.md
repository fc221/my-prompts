## 是什么

每月按“应发 → 扣社保公积金个人部分 → 按累计预扣法算个税 → 实发”的顺序算出每个人的工资，再用公式批量生成每人一条、带表头的工资条，方便打印裁开或逐人发送。

## 适合

几人到几百人的公司、门店，人事或会计每月算薪；核对银行代发金额和个税申报数据。

## 不适合

个税以税务申报系统算出的结果为准，表里的个税用来核对和预估；计件、阶梯提成规则很多的，用薪酬系统；出勤和加班数据来自「考勤表」。

## 注意

计算顺序不能乱：缺勤扣款在算个税之前扣（减少应发），餐费、借款这类税后扣款在算完个税之后扣，混在一起个税就算错了。个税税率表、每月减除费用、社保公积金比例和缴费基数上下限每年、各地都可能调整，全部放在参数表，以当年和当地最新规定为准，表里的数字只作演示。

## 要点

- 工作表：参数（社保公积金个人比例、缴费基数上下限、每月减除费用、个税预扣率表：累计应纳税所得额下限、预扣率、速算扣除数、计薪天数）、员工表（工号、姓名、部门、入职日期、基本工资、岗位工资、社保基数、公积金基数、每月专项附加扣除）、每月一张工资表（超级表命名 工资_01 … 工资_12，复制上月再改）、工资条。
- 应发：基本工资、岗位工资按工号 XLOOKUP 员工表；绩效、补贴、税后扣款手填；缺勤天数、加班时长按工号从考勤汇总取；缺勤扣款 =ROUND(([@基本工资]+[@岗位工资])/计薪天数*[@缺勤天数],2)，计薪天数如 21.75，按公司制度和当地规定；应发合计 = 各项收入 − 缺勤扣款。
- 社保公积金个人部分：缴费基数 =MEDIAN(基数下限,[@社保基数],基数上限)，把基数夹在上下限之间；养老 =ROUND([@缴费基数]*养老个人比例,2)，医疗、失业同理，公积金按公积金基数和比例算，取整规则按当地；四项之和是专项扣除。示例按养老 8%、医疗 2%、失业 0.5%、公积金 7% 演示。
- 累计预扣的累计数：累计收入 =[@应发合计]+XLOOKUP([@工号],工资_09[工号],工资_09[累计收入],0)，1 月和年中新入职的人上月取不到，按 0 起算；累计减除费用 = 每月减除费用 × 本年在本单位的任职月数；累计专项扣除、累计专项附加扣除同样逐月累加。
- 个税：累计应纳税所得额 =MAX(0,累计收入−累计免税收入−累计减除费用−累计专项扣除−累计专项附加扣除−累计其他扣除)；累计应纳税额 =ROUND(所得额*XLOOKUP(所得额,税率表[下限],税率表[预扣率],,-1)-XLOOKUP(所得额,税率表[下限],税率表[速算扣除数],,-1),2)，税率表下限从 0 开始升序；已预缴 = 上月表的累计已缴；本月个税 =MAX(0,[@累计应纳税额]-[@已预缴])；累计已缴 = 已预缴 + 本月个税。
- 实发 = 应发合计 − 专项扣除 − 本月个税 − 税后扣款；合计行算应发、个人社保公积金、个税、实发；校验格 应发合计 − 各项扣款合计 − 实发合计 不为 0 标红；实发比上月变动超过 30% 标黄，提醒复核。
- 工资条：单独一张表，每人占 3 行（表头、数据、空行便于裁剪），A1 =CHOOSE(MOD(ROW()-1,3)+1,INDEX(工资_10[#Headers],COLUMN()),INDEX(工资_10,INT((ROW()-1)/3)+1,COLUMN()),"") 向右、向下填满 3 × 人数行；工资表改了工资条自动跟着变。要按人发送电子工资条时，见「模板填充批量出表」。
- 月底核对：实发合计 = 银行代发清单合计；个税合计和个税申报系统的本月应扣缴税额核对，不一致逐人查专项附加扣除和任职月数；个人社保公积金和缴费明细核对；发薪人数 = 「员工花名册」当月在职人数加当月离职仍发薪的人。

## 提示词

帮我做一份{公司类型，如 连锁门店}的月度工资表 Excel，月份 {月份}：
1. 参数表放社保公积金个人比例、缴费基数上下限、每月减除费用、个税预扣率表、计薪天数，数值先按 {所在城市和年度} 填，标注“以当年当地最新规定为准”。
2. 员工表：工号、姓名、部门、入职日期、基本工资、岗位工资、社保基数、公积金基数、专项附加扣除。
3. 每月一张工资表，计算顺序：应发（含加班费、补贴，减缺勤扣款）→ 个人社保公积金（基数夹在上下限之间）→ 累计预扣法个税（累计数从上月表按工号取，新入职从 0 起）→ 税后扣款 → 实发；加合计行和校验格。
4. 工资条表：每人 3 行（表头、数据、空行），用公式从工资表生成。
交付时说明哪些列手填、哪些是公式、每月新建工资表的步骤，并用 4 名示例员工（含一名年中入职、一名有缺勤）演示 1 月和 2 月的个税累计。
