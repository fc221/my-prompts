## 是什么

先在 Excel 里把表做好看：标题、表头、样式、公式、打印设置都定好，存成模板；代码只负责往指定位置填数，按门店、部门或客户循环，每个对象出一个文件或一张工作表。

## 适合

每月给 30 家门店各发一份对账单；每个客户一份报价单；固定格式的上报表；版式由业务同事维护、开发只管数据的场景。

## 不适合

格式简单、直接从数据生成更省事的，用「代码生成 Excel」；最终要发 PDF 或打印件的，用「服务端批量生成」。

## 注意

填数位置不要在代码里写死成 B7、C12：在模板里给单元格起定义名称（门店名、统计月），或者在单元格里放占位文字（«门店»），代码按名字找。模板一改版，写死的坐标就全错了。明细行数不固定时，openpyxl 的 insert_rows 不会改公式引用和合并区域，所以合计放在明细上方，明细从样板行往下直接写。

## 要点

- 模板放在仓库的 templates 目录，文件名带版本号（门店对账单_v3.xlsx）；模板里另建“填写说明”表，列出每个定义名称或占位符的含义和数据来源。
- Python 用 openpyxl：每份都重新 load_workbook 模板，按 wb.defined_names["门店名"].destinations 拿到工作表和单元格地址再赋值，最后另存为新文件；不在同一个对象上反复改再另存。
- 明细区：模板第一行明细是样板行，带好边框、数字格式和公式；代码逐行写值，并把样板行每格的 font、border、number_format、fill 复制到新行；合计放在明细上方，求和范围预留到足够大（如 =SUM(E8:E5000)），不依赖最后一行的行号。
- JavaScript 用 ExcelJS：workbook.xlsx.readFile 读模板，getCell 赋值，写完用 writeBuffer 返回下载；ExcelJS 读写会丢掉模板里的图表，带图表的模板改用 openpyxl，或者图表放在另一份不经过代码的文件里。
- openpyxl 读写会丢掉形状、文本框、切片器和迷你图；带这些内容的看板模板，改成代码只写数据工作表，看板页的透视表设为“打开文件时刷新数据”。带宏的模板用 keep_vba=True 打开，另存为 .xlsm。
- 输出文件名用“模板名_对象_期间”（门店对账单_春熙路店_2026-10.xlsx），去掉 \ / : * ? " < > | 这些文件名不允许的字符；全部生成后打成 zip，附一份生成清单：对象、文件名、行数、合计金额、状态。
- 一份失败不影响其他：逐份捕获错误，记录原因（缺数据、超出模板预留行数），继续下一份；结束后输出成功数和失败清单。
- 生成后抽查：重新读入几份，核对明细行数和金额合计；模板里的公式要在 Excel 打开时才重算，代码里需要的合计自己另算一遍。

## 提示词

给{项目}写一个按模板批量生成 Excel 的功能：用模板 {模板文件，如 templates/门店对账单_v3.xlsx}，按{分组对象，如 门店}每个对象生成一份，数据来自{数据来源，如 订单表 10 月数据}，用{openpyxl / ExcelJS}。
1. 先打开模板，列出里面的定义名称、占位符、样板行位置、公式和打印设置；没有定义名称的，先告诉我需要给哪些单元格起名，不在代码里写死坐标。
2. 表头区按名称填：{表头字段，如 门店名、统计月、期初余额}。
3. 明细区从样板行开始逐行写{明细列，如 日期、单号、摘要、金额}，每行复制样板行的字体、边框、数字格式和填充；合计放在明细上方、求和范围预留到足够大，不用 insert_rows。
4. 每份都重新读取模板再填，另存为“{模板名}_{对象名}_{期间}.xlsx”，去掉文件名里的非法字符。
5. 单份出错时记录原因并继续；全部完成后打包成 zip，附生成清单（对象、文件名、行数、合计、状态）。
6. 模板里有图表、切片器、迷你图或宏时，先告诉我会不会被丢掉，再选处理办法。
7. 写测试：用 3 个对象的样例数据生成，读回检查定义名称处的值、明细行数和合计金额。
完成后说明改了哪些文件，以及模板以后改版时需要注意什么。
