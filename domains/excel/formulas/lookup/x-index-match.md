## 是什么

MATCH 找到值在第几行（或第几列），INDEX 按位置取值，两个组合能向任意方向查、按行列标题交叉取值，也能同时满足好几个条件；所有版本的 Excel 和 WPS 都能用。

## 适合

按 门店 + 商品 查单价、按 工号 + 月份 查绩效；从运费表、提成表这种行列都有标题的二维表交叉取值；要兼容低版本又想避开 VLOOKUP 数列号的麻烦。

## 不适合

单个条件且大家都是新版本时，「XLOOKUP 查找」更短；要对满足条件的多行求和，用「条件求和与计数」里的 SUMIFS。

## 注意

多条件的数组写法在 Excel 2019 及更早版本里要按 Ctrl+Shift+Enter 输入，直接回车会得到 #N/A 或错误结果；不想记三键，就用下面套一层 INDEX 的写法或辅助列。数组运算的范围写到实际行数（如 $A$2:$A$2000）或用超级表列，整列 A:A 会让文件明显变慢。

## 要点

- 单条件：=INDEX(商品表!$C$2:$C$500,MATCH(B2,商品表!$A$2:$A$500,0))；MATCH 第 3 个参数写 0 精确匹配，返回列在查找列左边也能查。
- 多条件（Microsoft 365、Excel 2021 及以上直接回车）：=INDEX(价格表[单价],MATCH(1,(价格表[门店]=B2)*(价格表[商品]=C2),0))；两个条件相乘，同时成立的位置结果为 1。
- 多条件（所有版本，免三键）：=INDEX(价格表[单价],MATCH(1,INDEX((价格表[门店]=B2)*(价格表[商品]=C2),0),0))，内层 INDEX(…,0) 让普通回车也按数组计算。
- 辅助列写法（最快、最好排查）：价格表加一列 键 =[@门店]&"|"&[@商品]，查找写 =INDEX(价格表[单价],MATCH(B2&"|"&C2,价格表[键],0))；分隔符避免“A1”+“0”和“A”+“10”拼成同一个键。
- 新版本更短的写法：=XLOOKUP(1,(价格表[门店]=B2)*(价格表[商品]=C2),价格表[单价],"无报价")，需要 Microsoft 365 或 Excel 2021 及以上，WPS 新版也支持。
- 二维交叉：=INDEX($B$2:$F$20,MATCH(H2,$A$2:$A$20,0),MATCH(I2,$B$1:$F$1,0))，一个 MATCH 找行、一个找列。
- 找不到：外面套 =IFNA(…,"无报价")（Excel 2013 及以上），只处理“查不到”，其他错误照常显示，见「错误值处理」。

## 提示词

帮我在{工作表名，如 订单}里按{条件列，如 门店和商品}两个条件，从{参照表，如 价格表}查出{返回列，如 单价}：
1. 先读两张表，确认条件列在两边写法一致（没有多余空格、名称统一），参照表里同一组条件只有一行，有重复的列出来。
2. 参照表做成超级表。用户版本是 {Excel 版本，如 Microsoft 365 / Excel 2016}：新版本用 INDEX + MATCH 的数组写法或 XLOOKUP；低版本用套一层 INDEX 的免三键写法。
3. 另给一份辅助列写法：参照表加 键 列，用“|”拼接条件。
4. 查不到时用 IFNA 显示“{缺失提示，如 无报价}”。
5. {二维表，如 运费表按 地区 × 重量段} 用 INDEX 加两个 MATCH 交叉取值。
交付时说明每个公式需要的版本和输入方式（直接回车还是三键），并用 3 行示例数据验证结果。
