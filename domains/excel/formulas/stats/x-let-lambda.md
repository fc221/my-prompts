## 是什么

LET 在公式里给中间结果起名字，同一段计算只写一次、只算一次；LAMBDA 把一段公式包装成自定义函数，在名称管理器里起个名字后，像内置函数一样调用，如 =毛利率(C2,D2)。

## 适合

一个公式里同一段 SUMIFS 或查找重复出现好几次；全表反复用到的口径计算（毛利率、含税价、工龄）；想让长公式能被别人读懂。

## 不适合

文件要给低版本 Excel 或其他表格软件打开，改用辅助列分步计算；只用一两次的简单公式不必包装。

## 注意

LAMBDA 自定义函数保存在当前工作簿的名称里，公式复制到别的工作簿时，如果那边没有同名名称就会变成 #NAME?；要在目标工作簿里重新定义一遍，并在说明表里列出自定义函数和参数含义。

## 要点

- LET 写法：=LET(名称1,值1,名称2,值2,…,最后的计算)；名称可以用中文，不能和单元格地址重名（A1、Q4、R1C1 这类不能当名称）。
- 去重复计算：=LET(收入,SUMIFS(订单[金额],订单[门店],A2),成本,SUMIFS(订单[成本],订单[门店],A2),IF(收入=0,"",(收入-成本)/收入))，两段 SUMIFS 各算一次。
- 先在单元格里试：=LAMBDA(收入,成本,IF(收入=0,"",(收入-成本)/收入))(B2,C2)，结果对了再放进名称管理器。
- 定义自定义函数：公式 → 名称管理器 → 新建，名称 毛利率，引用位置 =LAMBDA(收入,成本,IF(收入=0,"",(收入-成本)/收入))，备注里写参数含义；之后任意单元格写 =毛利率(B2,C2)。
- 逐行计算：=BYROW(C2:E20,LAMBDA(行,SUM(行))) 每行求和后溢出成一列；=MAP(B2:B20,C2:C20,LAMBDA(收入,成本,毛利率(收入,成本))) 两列逐个配对计算。
- 版本：LET 需要 Microsoft 365 或 Excel 2021 及以上；LAMBDA、BYROW、MAP 需要 Microsoft 365 或 Excel 2024；WPS 新版支持 LET，LAMBDA 以所用版本的插入函数里能否搜到为准。
- 低版本替代：把 LET 里的每个名称变成一列辅助列（收入、成本、毛利率），列名就是原来的名称；自定义函数改成整列复制同一公式。

## 提示词

帮我用 LET 和 LAMBDA 简化{工作簿名，如 门店利润分析}里的公式：
1. 先读现有公式，找出同一段计算重复出现的地方（如重复的 SUMIFS、XLOOKUP），列出每处的位置。
2. 用 LET 改写这些公式，中间结果用业务词命名（{名称示例，如 收入、成本、毛利}），结果和改写前逐格对比一致。
3. 把全表反复用到的口径 {口径，如 毛利率、含税价} 定义成 LAMBDA 自定义函数，写清参数和备注，并在说明表里列出。
4. 用户版本是 {Excel 版本}：没有 LAMBDA 时只用 LET；连 LET 也没有时改成辅助列。
交付时列出改写前后的公式对照、新增的名称，以及需要的最低版本。
