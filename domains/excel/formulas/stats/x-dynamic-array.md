## 是什么

一个公式返回一整片结果，自动“溢出”到下方和右侧的空单元格：FILTER 按条件筛出多行，UNIQUE 去重，SORT、SORTBY 排序，SEQUENCE 生成序号。源数据变了，结果的行数和内容跟着变，不用拖公式。

## 适合

按条件列出明细（某门店的待发货订单）；生成不重复的门店、客户清单作为汇总表的行标题；销售排行榜；随数据自动扩展的下拉来源。

## 不适合

文件要给 Excel 2019 及更早版本的人用；超级表内部（溢出公式在超级表里会报 #SPILL!，结果放在表外的普通区域）；数据量大、要随时切换维度的分析用「数据透视表」。

## 注意

溢出区域里只要有一格不空（哪怕只是一个空格字符或合并单元格），整个公式就报 #SPILL!，结果下方和右侧要留够空位。引用溢出结果时写左上角地址加 #，如 F2#，结果行数变了引用跟着变。

## 要点

- 按条件筛：=FILTER(订单[[订单号]:[金额]],(订单[门店]=I1)*(订单[状态]="待发货"),"无记录")；几个条件同时满足用 * 相乘，满足其一用 + 相加，第 3 个参数是筛不出时显示的内容。
- 去重清单：F2 写 =SORT(UNIQUE(订单[门店]))，G2 写 =SUMIFS(订单[金额],订单[门店],F2#)，就是一张随新门店自动变长的汇总表。
- 排行榜：=SORTBY(F2#,G2#,-1) 按金额从高到低列出门店；只要前 10 名再套 TAKE(…,10)，TAKE 需要 Microsoft 365 或 Excel 2024。
- 序号：=SEQUENCE(ROWS(F2#)) 给清单编号，行数随清单变化。
- 动态下拉：数据验证的序列来源写 =$F$2#，清单变长后下拉自动多出新选项。
- 版本：FILTER、UNIQUE、SORT、SORTBY、SEQUENCE 需要 Microsoft 365 或 Excel 2021 及以上，WPS 新版也支持；在旧版本里打开会显示 #NAME?，或变成固定大小、不再扩展的旧式数组公式。
- 低版本替代：去重用 数据 → 删除重复项，或把门店拖到「数据透视表」的行；条件筛选用 自动筛选 或 高级筛选。
- 低版本的公式写法（K1 是所选门店）：明细加辅助列 H2 =IF(AND(B2=$K$1,D2="待发货"),MAX($H$1:H1)+1,"")，结果区第 n 行写 =IFERROR(INDEX(订单!A:A,MATCH(ROW(A1),订单!$H:$H,0)),"")，向右向下拖出。

## 提示词

帮我在{工作表名，如 门店看板}里用动态数组公式做{用途，如 门店销售汇总和待发货清单}：
1. 先读明细表 {明细表名，如 订单} 的结构，确认结果区放在超级表外面，下方和右侧留够空位。
2. 用 SORT(UNIQUE(…)) 生成不重复的 {维度，如 门店} 清单，旁边用 SUMIFS 引用 F2# 算 {汇总值，如 销售额}，再用 SORTBY 生成排行榜。
3. 用 FILTER 列出 {筛选条件，如 所选门店的待发货订单}，所选门店来自一个下拉格，筛不出时显示“无记录”。
4. 下拉的序列来源引用溢出区域，新增门店后自动出现。
5. 用户版本是 {Excel 版本}：低于 Excel 2021 时改用透视表或辅助列 + INDEX/MATCH 的写法。
交付时标出每个溢出公式所在的单元格和它的溢出范围，说明需要的版本。
