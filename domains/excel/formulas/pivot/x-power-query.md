## 是什么

Excel 自带的数据整理工具（数据 → 获取和转换数据）：把一个文件夹里几十个格式相同的表合成一张，去标题行、去空行、拆列、改类型、逆透视、按编号合并两张表；每一步都记在“应用的步骤”里，下个月放进新文件，点“全部刷新”就重做一遍。

## 适合

各门店每月交上来的同格式表要汇总；系统导出的数据每次都要同样清洗；二维表转一维表；两张表按编号关联，代替整列的 VLOOKUP。

## 不适合

一次性的少量整理，用 分列、快速填充 更快；逻辑复杂、要定时自动跑或多人协作维护的数据流程，改用 Python，见「用 pandas 清洗合并」。

## 注意

文件夹里每个文件的表头必须一致：合并按列名对齐，多一个“合计”行、改了一个列名，刷新就会报错或多出空列。门店模板要锁定表头（见「保护公式与录入区」），合并后先核对行数和金额合计是否等于各文件之和。

## 要点

- 合并文件夹：数据 → 获取数据 → 来自文件 → 从文件夹，选存放各门店表的文件夹 → 合并并转换数据，选示例文件里的工作表；保留 Source.Name 列，从文件名拆出门店和月份。
- 清洗步骤按顺序做：删除最前面几行（标题和说明）→ 将第一行用作标题 → 删除空行 → 筛掉“合计”行 → 更改类型（日期列设为日期，金额设为小数）。
- 逆透视：选中 门店、品类 这些标识列 → 转换 → 逆透视其他列，把 1 月、2 月……变成 月份、销售额 两列。
- 合并查询：主页 → 合并查询，两张表都选 商品编号 列，联接种类选“左外部”，再展开需要的 名称、单价 列。
- 文本清洗：转换 → 格式 → 修整、清除，去掉首尾空格和不可见字符；替换值统一名称，如把“滨江门店”替换成“滨江店”。
- 加载：关闭并上载至 → 新工作表的表，或“仅创建连接”后直接做透视表；查询结果表不手改，手改的内容下次刷新会被覆盖。
- 刷新：数据 → 全部刷新；文件夹路径变了在 数据源设置 里改；需要时在 查询属性 里勾选“打开文件时刷新数据”。
- 版本：Excel 2016 及以上和 Microsoft 365 内置，Excel 2010、2013 需要单独安装 Power Query 加载项；Mac 版 Microsoft 365 能用，但支持的数据源比 Windows 版少；查询的编辑和刷新放在 Windows 版 Excel 里做，WPS 打开时只当普通结果表使用。

## 提示词

帮我用 Power Query 合并整理{数据来源，如 各门店每月交的销售表}：
1. 先打开 2–3 个样本文件，列出表头、标题行、合计行、空行的位置，以及各文件之间不一致的地方。
2. 从文件夹 {文件夹说明，如 门店月报/2026} 合并，保留文件名列并拆出 {从文件名提取的字段，如 门店、月份}。
3. 清洗：删除标题行、提升表头、删除空行和合计行、修整文本、统一名称，日期和金额设为正确类型。
4. {逆透视需求，如 把 1–12 月的列逆透视成 月份、销售额 两列}。
5. 与 {参照表，如 商品表} 按 {关联键，如 商品编号} 做左外部合并，带出 {要带出的列}。
6. 结果加载到新工作表的超级表，命名为 {结果表名}。
交付时列出查询的每个步骤和作用，说明下个月放入新文件后怎么刷新，并给出行数和金额合计的核对结果。
