## 是什么

用 设置单元格格式（Ctrl+1）→ 数字 → 自定义，改数字的显示方式而不改值：千分位、两位小数、百分比、按万元显示、日期带星期、负数标红，计算仍按原值进行。

## 适合

金额、数量、比率、日期的统一显示；报表按万元展示、明细保留到分；增长率带涨跌箭头；编号补足位数。

## 不适合

要真正改变数值的（四舍五入后再参与计算）用 ROUND；要把数字拼进一句话里用 TEXT 函数，见「文本拆分与合并」。

## 注意

格式只改显示：显示“12.3万”的格子值还是 123456，显示两位小数的格子背后可能有更多位，合计出现一分钱差额就是这么来的。金额要按显示精度计算时，在公式里写 =ROUND(数量*单价,2)，不勾选“将精度设为所显示的精度”（它会永久改掉原值）。

## 要点

- 金额：#,##0.00；负数标红：#,##0.00;[红色]-#,##0.00；零显示为短横线：#,##0.00;[红色]-#,##0.00;"-"。分号把格式分成 正数;负数;零;文本 四段。
- 百分比：0.0%，单元格里存 0.125；已经录成 12.5 的数再改成百分比格式会显示 1250.0%，要先除以 100。
- 万元：0!.0,"万" 把 123456 显示成 12.3万（逗号把数值缩小 1000 倍，!. 在倒数第一位数字前插入小数点）；百万用 #,##0.0,,。
- 日期：yyyy-mm-dd；带星期：yyyy-mm-dd aaaa 显示“2026-10-05 星期一”，aaa 只显示“一”；年月：yyyy-mm。
- 涨跌箭头：▲0.0%;[红色]▼0.0%;0.0%，负的增长率显示红色向下箭头。
- 补零编号：000000 让 123 显示成 000123；编号要参与查找时直接存成文本更稳。
- 一列只用一种格式，同列小数位一致；格式写进超级表的列或整列设置，新行自动沿用。
- 版本：自定义格式 Excel 各版本和 WPS 通用；颜色名在中文版写 [红色]，英文版写 [Red]，打开时会自动转换。

## 提示词

帮我统一{工作簿或报表名，如 门店月报}的数字格式：
1. 先读各工作表，列出每列现在的格式和不一致的地方（小数位不同、百分比录成整数、日期是文本）。
2. 按列设置：金额 #,##0.00，负数红色、零显示短横线；比率 0.0%；{万元列，如 销售额汇总} 用 0!.0,"万" 显示万元；日期 yyyy-mm-dd；{编号列} 补零到 {位数} 位。
3. 增长率列用涨跌箭头格式。
4. 金额计算公式里加 ROUND 保留两位小数，保证合计和明细一致。
5. 格式设在超级表的整列上，新增行自动沿用。
交付时列出每列的格式代码，并说明哪些列只是显示变了、值没有变。

      widths: [52, 60, 56, 54, 118],

      ],
      fx: ['B2', '123456'],
      tabs: ['月报', '明细'],
    }),
    boxes([
      { t: '销售额', items: ['0!.0,"万"'], acc: true },
      { t: '环比', items: ['▲0.0%;[红色]▼0.0%;0.0%'] },
      { t: '毛利率', items: ['0.0%'] },
      { t: '更新日期', items: ['yyyy-mm-dd aaaa'] },
    ], { cols: 1 }),
  ], { title: '数字格式 · B2 显示 12.3万，编辑栏里的值仍是 123456', min: 0.45 });

  root.querySelectorAll('.xc').forEach((c) => {
    const t = c.textContent;
    if (/^\[▼.*\]$/.test(t)) { c.textContent = t.slice(1, -1); c.classList.add('m-bad'); }
    if (/^[▲▼]?[\d.,]+(万|%)$/.test(c.textContent) || /星期/.test(t)) c.classList.add('r');
  });
}
</script>
