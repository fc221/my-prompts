## 是什么

选中数据按 Ctrl+T（插入 → 表格），把一片区域变成有名字的“表”：新增的行自动带上格式、公式和数据验证，公式里用 订单[金额]、[@数量] 这样的列名代替 F2:F500，范围随行数自动伸缩。

## 适合

订单、流水、库存这类一维明细；被透视表、图表、下拉列表和 Power Query 引用的数据源，加了新行不用再改引用范围。

## 不适合

打印用的报表和带合并单元格的表单；要两行表头的表（超级表只有一行表头）；溢出型公式（FILTER、UNIQUE 这类）的结果区域，放到表外的普通单元格。

## 注意

建表后马上在“表设计 → 表名称”里改名，如 订单、商品、门店表；默认的“表1”“表2”写进公式后谁也看不懂。表名以文字或下划线开头，不能有空格，不能和单元格地址同名。

## 要点

- 计算列：在表右侧空列的第一行写 =[@数量]*[@单价]，整列自动填同一公式，新行自动带出；同一列里别手改个别单元格，否则会出现“公式不一致”的绿色三角。
- 引用写法：整列 订单[金额]，本行 [@金额]，连续几列 订单[[日期]:[金额]]；在任何工作表里都能直接写 =SUMIFS(订单[金额],订单[门店],A2)，不用写工作表名。
- 公式向右拖动时列引用会跟着平移（订单[金额] 变成 订单[成本]）；要固定某一列写成 订单[[金额]:[金额]]。
- 汇总行：表设计 → 勾选“汇总行”，在下拉里选求和、计数，生成的是 =SUBTOTAL(109,[金额])，筛选后只统计可见行。
- 下拉的序列来源不能直接写结构化引用：先在 公式 → 名称管理器 新建名称 门店列表，引用位置 =门店表[门店]，序列来源写 =门店列表；新增门店后下拉自动多一项。
- 一张工作表只放一张超级表，表的右边和下边留空，不和别的表挨着，避免插入行时互相挤压。
- 版本：Excel 2007 及以上都有；WPS 新版同样用 Ctrl+T 创建，打开别人的文件后先试一次在表尾加新行，确认公式和格式会自动带出。

## 提示词

帮我把{工作表名，如 订单}里的明细改成超级表：
1. 先读现有数据和公式，确认表头只有一行、没有合并单元格和小计行，有的话先整理成一维表。
2. Ctrl+T 建表，表名改为 {表名，如 订单}；参数类的数据（{参数表，如 门店、商品}）也各建一张表。
3. 把计算列改成结构化引用，例如 金额 =[@数量]*[@单价]；汇总表里的公式改成 订单[列名] 引用，替换掉 A2:A500 这种固定范围。
4. 下拉列表通过名称管理器引用参数表的列，新增选项后下拉自动更新。
5. 打开汇总行，金额列求和。
交付时列出每张表的表名和列名、哪些是计算列，并在表尾加 2 行示例数据，演示公式、格式和下拉会自动带出。
