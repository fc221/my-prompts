## 是什么

一行一条记录、一列一个字段的明细表：每行写清什么时候、哪个门店、什么商品、多少钱，月份、门店这些维度各占一列，不铺成表头。筛选、排序、SUMIFS、透视表和导入系统都以它为底稿。

## 适合

销售流水、出入库、报销明细、考勤打卡这类要筛选和汇总的原始数据；准备做「数据透视表」或交给别的系统导入的表。

## 不适合

给领导看的、要打印的汇总报表可以是二维表，但要由一维表透视或用公式生成，不手工维护；报销单、审批单这种一张纸一份的单据按表单排版。

## 注意

最常见的错是把月份或门店铺成表头（1 月、2 月、3 月……），每多一个月就要加一列、改一遍公式。已有的二维表用 Power Query 的“逆透视其他列”转成一维，见「Power Query 合并整理」。

## 要点

- 第一行是唯一的表头行，上面不放大标题和说明文字；标题写在工作表名上，说明放到单独的“说明”工作表。
- 每列只放一种数据：日期、门店、商品、数量、金额各一列；“1 月销量”这种把维度写进列名的表头，改成“月份”列加“销量”列。
- 每行信息填全：同一门店连续多行时每行都写门店名，不合并单元格，不留空格子表示“同上”。
- 明细里只有记录，不插小计行、合计行和空行；小计放到汇总表，用透视表或 SUMIFS 生成。
- 每条记录有一列唯一编号（订单号、单据号），用于查找、去重和对账。
- 二维表转一维：选中数据 → 数据 → 来自表格/区域 → 在编辑器里选中门店、品类这些标识列 → 转换 → 逆透视其他列，得到 门店、品类、月份、销售额 四列；Excel 2010、2013 要先装 Power Query 加载项。
- 已合并的单元格批量还原：选中该列 → 取消合并 → 开始 → 查找和选择 → 定位条件 → 空值 → 输入等号并点上方单元格 → Ctrl+Enter，最后整列复制、选择性粘贴为值。

## 提示词

帮我把{工作簿或工作表名，如 各门店月销量}整理成一维表：
1. 先读现有表，列出藏在表头里的维度（月份、门店、品类）、合并单元格、小计行和空行的位置。
2. 转成一维表，列为 {列清单，如 日期、门店、品类、商品、数量、金额}，每行一条记录、每格信息填全，去掉小计行、空行和合并单元格。
3. 加一列唯一编号 {编号列名}，格式 {编号格式，如 DD + 6 位数字}。
4. 转换用 Power Query 的逆透视完成并保留查询步骤，下个月放新数据后刷新即可；给出转换前后的行数和金额合计对比，证明没丢数据。
5. 原来的二维报表改到单独的“汇总”工作表，用透视表或 SUMIFS 从一维表生成。
交付时说明一维表每列的含义、哪些列手填、哪些列是公式或查询生成。
