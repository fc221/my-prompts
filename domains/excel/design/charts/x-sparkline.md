## 是什么

画在单元格里的小图。迷你图（插入 → 迷你图：折线、柱形、盈亏）每行画一条趋势；数据条、色阶、图标集属于条件格式，按数值给单元格画条、上色或加箭头。一张明细表扫一眼就知道谁高谁低、谁在涨。

## 适合

门店月度销售表、商品动销表、指标汇总页每行的趋势；行数多、不可能每行配一张正式图表的时候。

## 不适合

要看坐标和具体数值的趋势用正式图表，见「图表怎么选」；高亮重复值、到期提醒这类规则见「条件格式」。

## 注意

迷你图默认每行各自缩放纵轴：涨 2% 的和涨 200% 的画出来一样陡，行与行之间没法比。要横向比较，就把纵轴的最小值和最大值都设成“所有迷你图相同”。数据条同理，最小值和最大值改成固定数字，否则数据一变，所有条的比例都跟着变。

## 要点

- 迷你图：数据范围选一行的连续月份（如 B2:G2），位置范围选整列（H2:H20），一次插入成一组；以后加月份用“编辑数据”改整组的范围。
- 迷你图只标高点、低点和尾点，各用一种颜色；表示“达标 / 未达标”这类正负结果用盈亏迷你图；空单元格在“隐藏和空单元格”里设为空距。
- 数据条：其他规则里最小值和最大值的类型都选“数字”，达成率设 0 和 1；勾“仅显示数据条”时，数值另起一列显示；有负值时在“负值和坐标轴”里设负值颜色，坐标轴放在单元格中点。
- 图标集：规则类型改成“数字”，按环比判断：绿色上箭头为 ≥ 0.05，黄色横箭头为 ≥ −0.05，其余红色下箭头；越低越好的指标（退货率、成本）把图标次序反转。
- 色阶：只表示大小时用双色（白到一种颜色）；有好坏方向的（利润、偏差）用三色，中间值类型设为数字 0。
- 一列只用一种：数据条、色阶、图标集不叠在同一列；颜色含义整张表一致，绿表示好、红表示差。
- 迷你图是 Excel 2010 起的功能，WPS 也有。用 openpyxl 打开再保存会丢掉迷你图（它不读这部分），代码批量生成时用 xlsxwriter 的 add_sparkline。

## 提示词

帮我在 Excel 表“{工作表名}”里加迷你图和条件格式。表结构：A 列是{行对象，如 门店}，{起止列，如 B 到 G 列}是{期间，如 7–12 月}的{指标，如 销售额（万元）}，另有{其他列，如 H 列达成率、I 列环比}。
1. 在{迷你图列}为每行插入折线迷你图，整列一组；纵轴最小值和最大值都设为“所有迷你图相同”；只标高点、低点和尾点，空单元格显示为空距。
2. {达成率列}加数据条：最小值数字 0、最大值数字 1，超过 100% 的显示满格，数值保留在单元格里。
3. {环比列}加三向箭头图标集：≥ 0.05 绿色上箭头，≥ −0.05 黄色横箭头，其余红色下箭头；这些行是越低越好的指标，图标次序反转：{越低越好的行}。
4. 每一列只用一种条件格式，绿色表示好、红色表示差。
交付时写清每条条件格式的应用范围和规则；如果要用代码生成，用 xlsxwriter 的 add_sparkline 和 conditional_format，不用 openpyxl 改已有文件。

<script type="module">
import { draw, sheet } from '../../../frontend/_shared/diagram.ts';
export default function demo(root) {
  const rows = [
    ['春熙路店', 42, 45, 41, 48, 52, 57, '▮95 95%', '▲ 9.6%'],
    ['太古里店', 61, 58, 55, 53, 50, 47, '▮78 78%', '▼ 6.0%'],
    ['交子大道店', 30, 33, 35, 34, 38, 41, '▮100 103%', '▲ 7.9%'],
    ['天府广场店', 50, 49, 52, 51, 50, 51, '▮93 93%', '► 2.0%'],
    ['双流机场店', 22, 28, 35, 31, 26, 24, '▮69 69%', '▼ 7.7%'],
  ];
  // 所有行共用一根纵轴（20–62），对应“所有迷你图相同”
  const spark = (vals) => {
    const xy = vals.map((v, i) => [3 + i * 10.8, 14 - ((v - 20) / 42) * 12]);
    const hi = vals.indexOf(Math.max(...vals)), lo = vals.indexOf(Math.min(...vals)), end = vals.length - 1;
    const dot = (i, c) => `<circle cx="${xy[i][0]}" cy="${xy[i][1]}" r="1.9" fill="${c}"/>`;
    return `<svg class="m-sp" viewBox="0 0 60 16" aria-hidden="true"><polyline points="${xy.map((p) => p.join(',')).join(' ')}" fill="none" stroke="#5b7fb0" stroke-width="1.4" stroke-linejoin="round"/>${dot(hi, '#1baf7a')}${dot(lo, '#e34948')}${end !== hi && end !== lo ? dot(end, '#2a78d6') : ''}</svg>`;
  };
  const html = sheet({
    head: ['门店', '5 月', '6 月', '7 月', '8 月', '9 月', '10 月', '趋势', '达成率', '环比'],
    widths: [74, 40, 40, 40, 40, 40, 40, 72, 84, 64],
    rows: rows.map((r, i) => [r[0], ...r.slice(1, 7).map(String), 'SPK' + i, r[7], r[8]]),
    fx: ['J3', '=G3/F3-1'],
    marks: { J2: 'good', J3: 'bad', J4: 'good', J5: 'warn', J6: 'bad' },
    tabs: ['门店月报', '目标', '数据'],
    freeze: true,
  }).replace(/SPK(\d)/g, (_, i) => spark(rows[i].slice(1, 7)));
  draw(root, `<div class="m-fit">${html}</div>`, { title: '迷你图纵轴统一 · 数据条 0–100% · 箭头按环比 ±5%', min: 0.45 });
}
</script>
