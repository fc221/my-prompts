## 是什么

把要别人填的格子解锁、公式和表头保持锁定，再开启“保护工作表”：填表的人只能改录入区，公式不会被误删、覆盖或拖乱。

## 适合

发给门店、员工填写的模板；带公式的报价单、工资表、预算表；多人共用的台账。

## 不适合

防泄密：工作表保护的密码很容易被绕过，只能防误操作；敏感数据用 文件 → 信息 → 保护工作簿 → 用密码进行加密，或者只发需要的部分。

## 注意

所有单元格默认就是“锁定”的，只是没开保护所以不生效；顺序必须是先解锁录入区，再保护工作表。超级表在受保护的工作表里不会自动扩展，要预留足够的空行，或者录入表不开保护、只保护汇总表。

## 要点

- 第一步：选中录入区（如 B4:E40）→ Ctrl+1 → 保护 → 取消勾选“锁定”；录入区填浅黄底色，让人一眼看出哪里能填。
- 第二步（可选）：选中要藏起来的公式格 → Ctrl+1 → 保护 → 勾选“隐藏”，保护后编辑栏不显示公式。
- 第三步：审阅 → 保护工作表，只保留“选定锁定单元格”“选定未锁定的单元格”，按需要加勾“使用自动筛选”“设置列格式”。
- 不同的人改不同区域：审阅 → 允许编辑区域，给每块区域单独设密码，如门店填 B–E 列、财务填 F 列。
- 防止删除、改名、移动工作表：审阅 → 保护工作簿（结构），和保护工作表是两回事，需要时两样都开。
- 密码记在团队的密码记录里，丢了只能重做模板；说明表里写明哪些表受保护、找谁要密码。
- 检查：保护后按 Tab，光标只在未锁定的格子间跳；在公式格里输入应弹出“受保护”提示。
- 版本：Excel 各版本和 WPS 都支持，WPS 的入口同样在 审阅 → 保护工作表。

## 提示词

帮我给{模板名，如 门店月度费用申报表}设置保护：
1. 先读模板，列出录入区（{录入区，如 B4:E40}）、公式区和表头，确认所有公式都在锁定区里。
2. 录入区取消锁定并填浅黄底色；{要隐藏的公式列，如 合计和审核状态} 勾选“隐藏”。
3. 保护工作表，只允许选定单元格和使用自动筛选，密码设为 {密码}。
4. {多人分区，如 门店填费用、财务填审核} 用“允许编辑区域”分别设密码。
5. 保护工作簿结构，防止删除和改名工作表。
6. 如果录入表是超级表，预留 {预留行数} 行空行，并说明保护后不能自动扩展。
交付时列出锁定区、录入区和各区域密码的位置，写一段给填表人的说明，并说明怎么用 Tab 键检查保护是否生效。
