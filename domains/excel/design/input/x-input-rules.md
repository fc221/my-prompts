## 是什么

让每个值都能被公式、筛选和透视正确识别的录入规则：日期是真日期、数字是真数字、同一个东西只有一种写法、单位和备注不混进数值、一格只放一个值。

## 适合

发给门店、分公司、员工填写的收集表；多人共用的台账；后面要汇总分析的明细。

## 不适合

已经收上来的大批脏数据，先用「Power Query 合并整理」清洗，再按本条改模板，从源头防止。

## 注意

看起来对不等于真的对：左对齐、左上角带绿色三角的数字是文本，SUM 会漏掉；“2026.10.5”“10月5号”也是文本，不是日期。用 =ISNUMBER(B2) 检查，真日期和真数字都返回 TRUE。

## 要点

- 日期统一录成 2026-10-05 或 2026/10/5，列格式设为日期；已录成“2026.10.5”的，选中整列用查找替换把“.”换成“-”即可变成真日期。
- 数量和金额只填数字，单位写进表头，如 数量（杯）、金额（元）；“35元”“约 20”拆成数字列加备注列。
- 编号、手机号、身份证号先把整列设为文本格式再录入：身份证号按数字录入时，15 位以后的数字会变成 0，且无法恢复。
- 门店、部门、商品这类名称用下拉选择，同一个门店只有“滨江店”一种写法，见「下拉与数据验证」。
- 一格只放一个值：“拿铁×2、美式×1”拆成多行，“陈立 13812345678”拆成姓名和电话两列。
- 空值就留空，“无”“-”“/”这类占位符号一律不填；值确实是 0 才填 0。
- 文字前后不加空格对齐；已有的用 =TRIM(B2) 清掉，网页复制来的不间断空格用 =SUBSTITUTE(B2,CHAR(160),"") 去掉。
- 模板里的填写示例放在“说明”工作表或单元格批注里，不占明细表的数据行，免得被当成真实记录汇总。

## 提示词

帮我给{用途，如 门店每日销售收集表}写一份录入规范，并按规范改好模板：
1. 先读现有模板和已收上来的几份数据，列出出现过的问题：文本型日期、带单位的数字、同一名称多种写法、一格多个值、多余空格。
2. 按列写规则：{列清单，如 日期、门店、商品、数量（杯）、金额（元）、备注} 各自的格式、单位和取值范围。
3. 模板里落实：日期和数值列设好格式，编号列设为文本，名称列做下拉，数量和日期加数据验证。
4. 写一张“说明”工作表，用 3 行示例说明正确填法和常见错误。
5. 给出一个检查公式列，用 ISNUMBER 等函数标出不合规的行。
交付时说明哪些列由填表人填写、哪些列是公式，以及收回数据后怎么快速检查。
