## 是什么

顾客付款后拿到的收款凭证，以及按月汇总给企业客户的对账单。正式的增值税电子发票（含数电票）只能由税务系统开具，业务系统自己生成的 PDF 只能叫“收款收据”“付款凭证”或“对账单”。

## 适合

门店消费、会员充值、订阅服务付款后的电子收据；企业客户的月度对账单；退款凭证。

## 不适合

要报销抵扣的发票：通过开票服务商的 API 在电子发票服务平台开具，拿回的 PDF / OFD 原样转给顾客，不自己排版；员工内部报销用「报销单」。

## 注意

自己生成的单据不仿照发票版式：标题不写“发票”，不印发票监制章、发票号码和税务二维码，免得被当成票据造假。页脚注明“本凭证不作为报销凭证，如需发票请在订单详情里申请开票”。

## 要点

- 区块顺序：抬头 → 单据信息 → 付款方 / 收款方 → 明细表 → 金额汇总 → 支付信息 → 备注 → 签章 → 页脚声明。
- 抬头：商户 logo 和全称、单据名（收款收据 / 对账单 / 退款凭证），单据名 18–20pt 居中；单据信息放右上：编号、开具日期、关联订单号。
- 编号 SJ-20261029-000123（类型前缀 + 日期 + 6 位流水，作废后不复用）；日期写 2026-10-29，时间到分 14:35；对账单写账期“2026-10-01 至 2026-10-31”。
- 付款方：名称、会员号或手机号（中间四位打码 138****6621）；收款方：商户全称、统一社会信用代码、门店地址、客服电话。
- 明细列：序号、项目、规格、数量、单位、单价、金额；金额两位小数、千分位、右对齐、等宽数字，写作“¥ 1,280.00”；折扣和优惠券单列为负数行。
- 汇总：小计、优惠、实收，实收下方写大写金额（人民币壹仟贰佰捌拾元整）；退款凭证的金额写负数，标题写明“退款凭证”。
- 支付信息：支付方式、交易流水号、支付时间；签章区在最后一页汇总的右下方，预留 40×40mm 放电子印章，旁边写经办人；要防篡改就加「数字签名」。
- 多页：页眉重复单据编号和商户名，汇总、支付信息、签章只在最后一页，页脚“第 X 页 / 共 Y 页”。

## 提示词

生成一份{商户类型}收款收据（同一套也用于月度对账单）的 PDF 模板，用{实现方式}实现（沿用项目现有的 PDF 生成方式）：
1. A4 竖版，四边距 15mm，正文思源黑体 10pt、行距 1.4。
2. 区块按顺序：抬头（logo、商户全称、单据名）→ 右上单据信息（编号 SJ-yyyyMMdd-6 位流水、开具日期 yyyy-MM-dd、订单号）→ 付款方（名称、手机号中间四位打码）和收款方（商户全称、统一社会信用代码、地址、客服电话）→ 明细表（序号、项目、规格、数量、单位、单价、金额）→ 汇总（小计、优惠、实收、大写金额）→ 支付信息（方式、流水号、时间）→ 备注 → 签章区（40×40mm 电子印章位、经办人）→ 页脚声明“本凭证不作为报销凭证”。
3. 金额两位小数、千分位、右对齐、等宽数字；大写金额用单独的函数生成，并对 0.05、100.00、10,010.50 这些边界值写单元测试。
4. 多页时页眉重复编号和商户名，汇总和签章只在最后一页，页脚“第 X 页 / 共 Y 页”。
5. 标题和正文都不出现“发票”字样，不放任何仿税务的章和二维码。
用 3 行和 60 行明细各生成一份样张，说明改了哪些文件。
